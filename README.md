# Kubernetes

This repository contains Kubernetes Helm chart examples and a local development environment.

## Helm

- [Files Methods](./helm/examples/Files) - Examples of Helm's .Files functions for working with files in templates 
- [Lookup API](./helm/examples/lookup-api) - Examples of Helm's lookup function for interacting with Kubernetes API to read deployment annotations
- [Dependencies](./helm/examples/dependencies) - Examples of using Helm chart dependencies with library charts for reusable components
- [Schema Validation](./helm/examples/schema) - Examples of Helm's schema validation feature using values.schema.json files

## Kubespray
- [Dev Cluster](./dev-cluster) - Local Kubernetes development environment
